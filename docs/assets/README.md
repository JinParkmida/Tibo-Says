# README typography and graphic

Original assets prepared for Tibo Says. The application source and its interface are unchanged.

| File | Purpose | Creation |
| :--- | :--- | :--- |
| `tibo-says-banner.svg` | Text-only README banner | Editable SVG typography. Heavy grotesk title, matching the original banner's type style. No illustration or raster image. |
| `how-it-works.svg` | Three-step explanation | Original editable SVG. |

The banner uses warm ivory and charcoal. The explanatory graphic retains its amber accents. Instructions remain in Markdown; the graphics are supplementary.

## Banner copy

Tibo says

Displays Tibo's tweets on your desktop.
If you don't know why you'd want that, you probably don't need it.

The banner was authored directly as SVG. No image generation was used for it. The title requests Arial Black, with Arial, Helvetica, and sans-serif fallbacks; body copy requests Arial with Helvetica and sans-serif fallbacks.
